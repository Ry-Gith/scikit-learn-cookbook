## Overview Repositori
Repositori ini berisi reproduksi kode program, eksperimen praktis komprehensif, serta penjelasan teoritis mendalam untuk **Chapter 1 sampai Chapter 13** (*scikit-learn Cookbook* & *Practical Machine Learning*).

## Daftar Struktur Notebook (Chapter 1 - 13)

| Nama File Notebook | Topik Utama & Penjelasan Konsep Teori |
|---|---|
| `Chapter 1.ipynb` | **Exploratory Data Analysis & Scikit-Learn API Basics**: Filosofi API scikit-learn (`fit`, `transform`, `predict`), Statistik Deskriptif (Mean, Trimmed Mean, Median, IQR), dan Pembuatan Custom Transformer. |
| `Chapter 2.ipynb` | **Data Preprocessing & Feature Engineering**: Penanganan Missing Values (`SimpleImputer`, `KNNImputer`), Scaling (`StandardScaler`, `RobustScaler`), Categorical Encoding (`OneHotEncoder`), dan `ColumnTransformer`. |
| `Chapter 3.ipynb` | **Dimensionality Reduction Techniques**: Reduksi Dimensi Linier & Non-Linier: PCA (Explained Variance Ratio), LDA (Supervised Discriminant), dan t-SNE (Manifold Learning). |
| `Chapter 4.ipynb` | **Distance Metrics & K-Nearest Neighbors**: Metrik Jarak (Euclidean $L_2$, Manhattan $L_1$, Minkowski $L_p$), Algoritma K-Nearest Neighbors (KNN), Sensitivitas Skala, dan Tuning Hyperparameter. |
| `Chapter 5.ipynb` | **Linear Models and Regularization**: Ordinary Least Squares (OLS), Regularisasi Ridge ($L_2$), Lasso ($L_1$), ElasticNet, dan Pemodelan Non-Linier dengan `SplineTransformer`. |
| `Chapter 6.ipynb` | **Advanced Logistic Regression & Multiclass/Multilabel**: Regresi Logistik Biner (Sigmoid & Log-Loss), Strategi Multiclass (OvR & Softmax), Multilabel Classification, dan Analisis Kurva ROC-AUC. |
| `Chapter 7.ipynb` | **Support Vector Machines & Kernel Methods**: Support Vector Classifier (SVC) & Regressor (SVR), Soft Margin & Parameter $C$, Kernel Trick (Linear, Polynomial, RBF), dan Tuning $\gamma$. |
| `Chapter 8.ipynb` | **Tree-Based Models & Ensemble Learning**: Decision Trees (Gini & Entropy), Bagging (Random Forest), Boosting (Gradient Boosting), dan Analisis Visual Feature Importances. |
| `Chapter 9.ipynb` | **Clustering Algorithms & Unsupervised Partitioning**: K-Means & K-Means++, DBSCAN (Density-based clustering & Noise Detection), Silhouette Score, dan Davies-Bouldin Index. |
| `Chapter 10.ipynb` | **Artificial Neural Networks & Multilayer Perceptrons**: Arsitektur Jaringan Saraf Tiruan (`MLPClassifier`), Fungsi Aktivasi (ReLU), Optimizer (Adam), Backpropagation, dan Weight Decay. |
| `Chapter 11.ipynb` | **Model Evaluation, Cross-Validation & Tuning**: Stratified K-Fold CV, `GridSearchCV` vs `RandomizedSearchCV`, dan Matriks Evaluasi Komprehensif (Precision, Recall, F1-Score). |
| `Chapter 12.ipynb` | **Pipeline Architecture & Custom Workflows**: Arsitektur Pipeline Kompleks, `FeatureUnion` (Ekstraksi Paralel), `TransformedTargetRegressor`, dan Pencegahan Data Leakage. |
| `Chapter 13.ipynb` | **Model Deployment & Production Workflows**: Serialisasi Model Biner (`joblib`), Verifikasi Inference Produksi, Penanganan Data Drift, dan Deployment Checklist. |
